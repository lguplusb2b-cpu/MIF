# MIF

MIF는 발주톡의 모바일 B2B 주문 흐름을 기준으로 구성하는 독립 Expo 앱입니다. 앱 이름, 패키지 식별자, API 주소, 데이터베이스 및 파일 저장소는 MIF 전용 환경을 사용해야 하며, 발주톡의 실제 거래처·주문·사업자 문서는 이관하지 않습니다.

## 현재 포함된 모바일 업무 흐름

| 영역 | 구현 범위 |
|---|---|
| 홈 | 빈 데이터 기반 주문 현황과 빠른 이동 |
| 상품 | 상품 등록·수정·삭제를 위한 상품 카탈로그 시작 화면 |
| 장바구니 | 품목별 수량 관리와 주문 생성 준비 |
| 주문 | 접수 → 결제확인 → 주문확정 → 상품준비 → 배송중 → 배송완료 상태 흐름 |
| 배송지 | 배송지 등록·수정·기본 배송지 지정·삭제 |
| 거래처 신청 | 사업자등록증 파일 선택을 포함한 신규 거래처 가입 신청 |
| 입점 문의 | 공급·유통 파트너 문의 접수 |
| 관리자 | 상품·주문·거래처 신청·입점 문의를 관리할 독립 메뉴의 시작점 |

## 실행

```bash
pnpm install
pnpm start
```

## MIF 운영 환경 연결 전제

운영 배포 전에는 MIF 전용 API 서버, 데이터베이스, S3 호환 파일 저장소, 푸시 알림 설정을 연결해야 합니다. 이 저장소의 로컬 상태 저장은 화면 흐름 검증을 위한 임시 개발 레이어이며, 실제 거래처·주문·문서를 포함하지 않습니다.
